# Как помочь проекту

Спасибо, что хотите помочь! Сообщения об ошибках, идеи и пул-реквесты — в [issues](https://github.com/CoolyWooly/ext_yandex_calendar/issues).

## Сообщить об ошибке

Опишите, что делали, что ожидали и что произошло, версию расширения (внизу страницы настроек), версию Chrome и ОС. **Не прикладывайте пароль приложения, адреса и названия встреч** — замените их на вымышленные.

## Разработка

Нужны Node.js 22 или новее и Google Chrome.

```bash
npm install
npm run dev         # сборка с пересборкой в .output/chrome-mv3-dev
npm test            # тесты (Vitest)
npm run typecheck   # проверка типов
```

Расширение из `.output/chrome-mv3-dev` загружается в `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное».

## Перед пул-реквестом

- `npm test` и `npm run typecheck` проходят.
- Новое поведение покрыто тестами в `tests/`.
- Код похож на окружающий: TypeScript, Preact, комментарии и тексты интерфейса — на русском.
- Ответы сервера для тестов (`tests/fixtures`) — только обезличенные: настоящие имена, адреса, ссылки и названия компаний замените.
- Если менялся интерфейс, обновите картинки магазина: `npm run store:assets`.
- Заметная для пользователя правка — строка в [CHANGELOG.md](CHANGELOG.md).

## Выпуск версии

1. Поднимите версию в `package.json` (`npm version X.Y.Z --no-git-tag-version`) и допишите раздел в `CHANGELOG.md`.
2. Закоммитьте и поставьте тег `vX.Y.Z`. После пуша тега GitHub Actions соберёт архив и создаст релиз.
3. Загрузите архив из релиза в [панель Chrome Web Store](https://chrome.google.com/webstore/devconsole). Тексты карточки — в [`store/listing.md`](store/listing.md).
