# Security — auth-retry-pause

- **Угроза:** частые неудачные входы с отозванным паролем приложения выглядят для Яндекса как подбор; возможна блокировка входа для аккаунта.
- **До:** каждое открытие окна, каждая правка настроек, запуск браузера — неудачный вход.
- **После:** автоматически — не чаще раза в 30 минут; сверх этого только явные действия пользователя («Обновить», ввод/перепроверка пароля). Пользователь не может случайно «нащёлкать» серию попыток, правя настройки.
- **Новые входные данные:** поле `manual` в сообщении `runtime` — сообщения принимаются только от страниц самого расширения (нет `externally_connectable`), подделать его извне нельзя. Худший случай — лишняя попытка входа, как от кнопки «Обновить».
- **Отключение аккаунта** во время паузы сразу удаляет встречи и напоминания из хранилища — данные отключённого аккаунта не остаются.
- Вердикт: ✅ можно выпускать.
