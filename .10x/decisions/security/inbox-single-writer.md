# Security — inbox-single-writer

- Новое сообщение `take-inbox` принимается только от страниц самого расширения (нет `externally_connectable`, нет content scripts). Худший случай злоупотребления — изменения считаются просмотренными; данных наружу не уходит.
- Ответ содержит те же данные о встречах, что окно и так читает из `chrome.storage`.
- Секреты, сеть, права манифеста не менялись.
- Вердикт: ✅ можно выпускать.
