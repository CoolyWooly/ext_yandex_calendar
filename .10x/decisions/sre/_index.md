## Ранбук: «встречи не обновляются»
1. Значок «!» → пароль приложения отозван: создать новый в Яндекс ID и ввести в настройках.
2. Баннер «Нет связи» → проверить сеть; расписание само вернётся к норме после успешной синхронизации.
3. Уведомлений нет → тестовое уведомление в настройках; в macOS — стиль «Постоянно», выключить «Не беспокоить».
4. Массовые жалобы → Яндекс поменял поведение CalDAV: снять свежий ответ, обезличить, добавить фикстуру и тест.
