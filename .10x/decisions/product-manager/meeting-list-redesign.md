# meeting-list-redesign — Product Manager

**Дата:** 2026-10-15 · Спека: [../../specs/2026-10-15-meeting-list-redesign-design.md](../../specs/2026-10-15-meeting-list-redesign-design.md)

## Запрос пользователя
Список встреч «Сегодня → встречи, Завтра → встречи, Среда → встречи…», без карточки «Следующая встреча»
и без плашки о приглашениях сверху; кнопка «Войти» — компактной иконкой. Дизайн показан макетом
и одобрен (с правкой: убрать плашку приглашений).

## Рамки
- В рамках: окно встреч — разбивка по дням, заголовки дней, карточка встречи, кнопка входа, выделение
  «скоро» и «идёт»; тексты README и карточки CWS про список; картинки магазина с окном встреч.
- Вне рамок: значок, уведомления, напоминания, настройки.

## Критерии готовности
- В окне нет «Следующая встреча», «Идёт сейчас», раздела «Сейчас» и плашки «… ждёт ответа».
- Встречи сгруппированы по дням: «Сегодня», «Завтра», день недели + дата серым.
- Вход в созвон — иконка с подсказкой «Войти · {провайдер}», залитая у своей встречи за 15 минут
  до начала и во время неё.
