## Privacy practices

**Single purpose:**

```text
Показывает пользователю его ближайшие встречи из Яндекс Календаря и напоминает о них: список встреч во всплывающем окне, отсчёт до начала на иконке и уведомления о встречах и их изменениях.
```

**Permission justification:**

| Разрешение | Обоснование |
|---|---|
| `storage` | Хранит настройки, данные подключения к календарю (почта и пароль приложения) и последний загруженный список встреч: окно открывается мгновенно, а новые данные сравниваются со старыми, чтобы уведомить о переносах и отменах. Всё хранится только локально. |
| `alarms` | Проверяет календарь по расписанию (раз в 1–5 минут, по выбору пользователя), срабатывает в момент напоминаний перед встречами и раз в минуту обновляет отсчёт до встречи на иконке. |
| `notifications` | Показывает напоминания перед началом встречи с кнопкой входа в созвон и уведомления о новых встречах, приглашениях, переносах и отменах. |
| Host permission `https://caldav.yandex.ru/*` | Единственный сервер, к которому обращается расширение: CalDAV-сервер Яндекс Календаря, с которого загружаются календари и встречи пользователя. Других сайтов расширение не открывает и содержимое вкладок не читает. |

**Are you using remote code?** No, I am not using remote code. Весь код в пакете, сторонний код не загружается.

**Data usage — какие данные отметить:**

- [x] Personally identifiable information — почта пользователя, имена и адреса организаторов встреч.
- [x] Authentication information — пароль приложения Яндекса.
- [x] Website content — содержимое встреч, загруженное с caldav.yandex.ru.
- Остальные пункты (health, financial, personal communications, location, web history, user activity) — не отмечать.

Данные не уходят дальше устройства и сервера Яндекса, но расширение их обрабатывает, поэтому честнее отметить. Отметить все три подтверждения:

- [x] I do not sell or transfer user data to third parties, outside of the approved use cases
- [x] I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- [x] I do not use or transfer user data to determine creditworthiness or for lending purposes

## Test instructions (для модератора)

Без аккаунта Яндекса модератор увидит только экран «Подключить календарь». Чтобы проверка прошла без вопросов, заведите отдельный тестовый аккаунт Яндекса с парой встреч в календаре, создайте для него пароль приложения «Календарь» и укажите в полях Username / Password. Текст инструкции:

```text
1. После установки откроется страница настроек (или: иконка расширения → «Подключить календарь»).
2. Введите почту из поля Username в «Рабочая почта», пароль из поля Password — в «Пароль приложения», нажмите «Проверить подключение».
3. Отметьте календарь «Мои события». Нажмите на иконку расширения — появится список встреч тестового аккаунта.
4. «Показать тестовое уведомление» на странице настроек показывает, как выглядят напоминания.
The extension only talks to caldav.yandex.ru. UI is in Russian.
```
