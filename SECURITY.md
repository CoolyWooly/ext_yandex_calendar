# Безопасность

## Как сообщить об уязвимости

Не публикуйте подробности уязвимости в открытом issue. Отправьте их приватно через [Security → Report a vulnerability](https://github.com/CoolyWooly/ext_yandex_calendar/security/advisories/new). Если эта форма недоступна, откройте issue с заголовком «Уязвимость» без подробностей — с вами свяжутся.

Исправления выпускаются для последней версии расширения.

## Что расширение делает с доступом к календарю

- Обращается только к `https://caldav.yandex.ru` по HTTPS. Других сетевых запросов нет, содержимое вкладок и история браузера не читаются.
- Почта и пароль приложения хранятся в `chrome.storage.local` в профиле Chrome **без шифрования**. Поэтому расширение работает только с паролем приложения: он даёт доступ лишь к календарю и отзывается в [Яндекс ID](https://id.yandex.ru/security/app-passwords) в один клик. Не вводите основной пароль от аккаунта.
- Если пароль приложения мог попасть к посторонним, отзовите его в Яндекс ID и создайте новый.
- Неверный пароль расширение проверяет не чаще раза в 30 минут, чтобы Яндекс не принял это за подбор.

Подробнее о данных — в [политике конфиденциальности](PRIVACY.md).
