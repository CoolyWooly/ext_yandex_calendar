# Встречи · Яндекс Календарь

Расширение для Chrome: показывает встречи из Яндекс Календаря (в том числе Яндекс 360 для бизнеса) и напоминает о них, чтобы не приходилось держать открытыми календарь и почту.

## Что умеет

- **Список встреч** по клику на иконку: «Сейчас», «Сегодня», «Завтра» и дальше на выбранное число дней. Кнопка «Войти» для Телемоста, Google Meet, Zoom, Teams, SberJazz и Контур.Толка, клик по встрече открывает её в Яндекс Календаре.
- **Значок на иконке**: минуты до следующей встречи за час до начала (последние 10 минут — оранжевым), «идёт» в первые 5 минут, красный счётчик непросмотренных изменений, «!» если Яндекс не принимает пароль.
- **Уведомления**: новая встреча или приглашение, перенос, изменение, отмена. Если изменений сразу много — одно общее уведомление.
- **Приглашения без ответа**, в том числе через рассылку: метка «нужно ответить» в списке и сводка раз в день после 9:00.
- **Напоминания** перед началом (по умолчанию за 10 и за 1 минуту) с кнопкой «Присоединиться». Висят, пока их не закрыть.

## Установка

Нужен Node.js 22 или новее.

```bash
npm install
npm run build
```

1. Откройте в Chrome `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное» и выберите папку `.output/chrome-mv3`.
3. Создайте пароль приложения: [Яндекс ID → Безопасность → Пароли приложений](https://id.yandex.ru/security/app-passwords) → «Календарь». Пароль даёт доступ только к календарю и отзывается в один клик.
4. На открывшейся странице настроек введите рабочую почту целиком (`name@company.ru`) и пароль приложения, нажмите «Проверить подключение» и отметьте календари. Календари переговорок лучше не отмечать.
5. Нажмите «Показать тестовое уведомление» — оно должно появиться и не исчезать.

Обновление: `git pull`, `npm run build`, затем кнопка обновления на карточке расширения в `chrome://extensions`.

## Уведомления в macOS

Если уведомлений нет или они пропадают через несколько секунд: «Системные настройки → Уведомления → Google Chrome» — разрешите уведомления и выберите стиль «Постоянно». В режиме «Не беспокоить» macOS их не показывает.

## Как это работает

- Встречи читаются по CalDAV с `caldav.yandex.ru`. Других сайтов расширение не открывает и вкладки не читает.
- Календарь проверяется по расписанию (по умолчанию раз в 2 минуты), при открытии списка и при смене настроек. Встречи скачиваются заново, только если календарь изменился (ctag), и раз в 15 минут на всякий случай.
- После ошибок проверки идут реже: при проблемах с сетью пауза растёт до 30 минут, неверный пароль проверяется раз в 30 минут — частые неудачные входы Яндекс может счесть подбором. Открытие списка и кнопка обновления пробуют сразу.
- Первая проверка после установки, смены аккаунта или обновления расширения «тихая»: расширение только запоминает, что уже есть.
- Всё хранится локально в профиле Chrome. Пароль приложения лежит в `chrome.storage.local` без шифрования — поэтому нужен именно пароль приложения, а не основной.

## Ограничения

- Ответить на приглашение можно только в самом Яндекс Календаре — расширение открывает встречу там.
- Списки задач («Не забыть») не показываются.
- У повторяющейся встречи Яндекс отдаёт одну ссылку на всю серию: «Открыть» может вести на её первую встречу.

## Разработка

```bash
npm test           # тесты (Vitest)
npm run typecheck  # проверка типов
npm run dev        # сборка с пересборкой при изменениях в .output/chrome-mv3-dev
```

Тестовые ответы сервера лежат в `tests/fixtures` — это реальные ответы Яндекса с заменёнными именами, адресами и ссылками.
